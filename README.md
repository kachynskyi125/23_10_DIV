# 🌌 Tajemství vesmíru

Tento projekt vznikl jako školní úkol zaměřený na efektivní komunikaci s umělou inteligencí, tvorbu vícestránkového webu a postupné verzování v Gitu/GitHubu.

## 📂 Struktura projektu
* `index.html` – Hlavní úvodní stránka
* `galerie.html` – Podstránka s obrázky vesmíru
* `o-mne.html` – Informace o projektu, použité zdroje a citace AI
* `style.css` – Společný externí vzhled webu

## 🚀 Technologie
* **HTML5** & **CSS3**
* **Git & GitHub** pro správu verzí

## 🤖 Použitá AI
* **Model:** Gemini (Google)
* **Způsob využití:** Asistence při generování struktury HTML stránek, návrhu CSS stylů a tvorbě textů.
